# jvlevinson — Project Documentation

Documentation hub for the **jvlevinson** repository. This is a GitHub *profile* repository: the root `/README.md` renders as the landing page of <https://github.com/jvlevinson>, and `/assets/github-metrics.svg` is regenerated by CI. See `/CLAUDE.md` for the operational rules that govern edits here.

Scaffolded in **Lite** mode — the sections below are the ones that exist. Sections from the full system (concerns, charts, standards, technical HLD/LLD, guides, scripts, decisions/ADR) are intentionally absent.

## Getting Started

1. Read the [structure guide](/docs/00-notes/02-documentation_structure_guide.md) for the naming and linking rules.
2. Copy the appropriate template from [00-templates](/docs/01-project/00-templates/README.md) into the target section.
3. Fill in the `ai_context` frontmatter — replace every `<...>` placeholder.
4. Stamp the file: `bash .scripts/cmd/bash/update-timestamp.sh -f <file> -s created`.
5. On every later edit, re-stamp with `bash .scripts/cmd/bash/update-timestamp.sh -f <file>`.

## Standards Summary

- **Numeric prefixes** on directories and files fix ordering (`00-`, `01-`, `97-`, `98-`, `99-`).
- **File naming**: `NN-{date}-NNN-CS-{descriptor}.md`.
- **Links are repo-rooted absolute** (`/docs/...`), never relative — they survive file moves.
- **`ai_context` frontmatter is mandatory** on every document.
- **Semantic versioning** (`vX.Y.Z`) in metadata; `created` never changes after it is first set.
- **Never hand-type timestamps.** The timestamp script is the only valid source.
